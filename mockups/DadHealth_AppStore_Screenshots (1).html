How to export App Store screenshots
Each screenshot above is sized at 430 x 932px (the proportional equivalent of iPhone 6.9" at 1290 x 2796px). To export at full App Store resolution:
1.
Open this file in Chrome on desktop
2.
Press Cmd+Shift+I (Mac) or F12 (Windows) to open DevTools
3.
Click the Toggle Device Toolbar icon (phone/tablet icon top left of DevTools) and set the width to 1290px and height to 2796px — this gives you true App Store resolution
4.
Press Cmd+Shift+P and type screenshot → select Capture full size screenshot
5.
Repeat for each screenshot — crop each one individually in Preview (Mac) or Photos (Windows)
App Store size requirements
iPhone 6.9" (required): 1320 x 2868px or 1290 x 2796px
iPhone 6.5" (required): 1284 x 2778px or 1242 x 2688px
