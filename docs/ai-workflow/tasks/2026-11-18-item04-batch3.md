- Tests: new `tests/mindPlanIntegration.test.mjs`; updated `mindPersonalisedPlan`, `mindFormation`, `mindJournalQuickFixes`, `todayScreen` and `proConversion` assertions only for approved changed behaviour.

Mutation locking is synchronous. An uncertain write retains its exact identity and triggers one read, not another write. Later normal focus/foreground/reopen reads reconcile it. A confirmed negative read permits only an explicit retry of that same operation. Failed access verification hides restricted content. There is no offline completion queue or polling. Native dismissal consumes owner/plan/action-bound destinations once; opening Journal or Reset does not complete anything.
